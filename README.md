# Hyderabad Home Kitchens

A responsive neighbourhood food-ordering website built with **HTML, CSS and JavaScript**.

## Features
- Choose a Hyderabad locality and see nearby home kitchens.
- Andhra and Telangana menu filtering.
- Food menu images and dish quantities.
- Demo sign-in/account using browser local storage.
- Shopping basket and checkout.
- Orders saved in the browser.
- Working order tracking: Ordered → Preparing → Packed → Out for delivery → Delivered.
- Responsive design for desktop and mobile.

## Run
Open `index.html` in a browser.

This is a front-end demo. Login and order data are stored locally in the browser; no real payment or server-side account system is connected.
